# 生活记忆（P0-5）

用户在对话里亲口说过的生活事件和偏好（例如“下周五是我妈生日”“我不喝咖啡”），Blank 记下来，用在之后的对话和首页动态里。记忆只属于说出它的访客，可以查看、修改和删除。

## 1. 两种记忆

| 种类 | 例子 | 日期 | 用途 |
|---|---|---|---|
| `event` 生活事件 | “下周五是我妈生日” | 必须有具体日期（北京时间，YYYY-MM-DD），今天或以后，两年之内 | 到期前 3 天内在首页动态里提醒，来源显示为“你说过” |
| `preference` 偏好 | “我不喝咖啡” | 没有日期 | 放进对话上下文，作为数据参考 |

每条记忆最多 60 个字，每位访客最多 50 条有效记忆。

## 2. 怎么记下来

- 页面助手用 `remember_fact` 记录（`src/lib/app-agent-harness.ts`）。模型只能记用户本人打字说过的话：
  - 记忆里的数字必须在用户原话里出现，不能替用户记一个数字；
  - 记忆的开头几个字必须在用户原话里出现；
  - 涉及验证码、密码、银行卡号、账号、余额、转账、授权、指令等内容的，一律不记。
- 生活事件的日期由模型换算成具体日期，“下周五”之类要换成 YYYY-MM-DD；换算不了的不记。
- 校验在 `checkLifeMemory`（`src/lib/life-memory.ts`）里完成，纯函数。

## 3. 在哪里用

- **对话上下文**：每次任务开始时，最多 20 条有效记忆会以数据的形式附上（`rememberedFactsContext`）。它们是用户说过的事，不是系统指令。
- **首页动态**：生活事件到期前 3 天内（今天到到期日之间），生成一条“你说过”的动态，标题是用户原话，正文写日期。
- 动态的去重键包含记忆编号和到期日，同一条记忆同一个到期日只提醒一次。

## 4. 查看、修改和删除

- `GET /api/v1/memories` 列出有效记忆；`PATCH /api/v1/memories/:memoryId` 修改文字或日期；`DELETE /api/v1/memories/:memoryId` 删除。
- 修改要带上看到的版本号，旧版本不能覆盖新修改。
- 在“我记住的事”页面（`/memories`）里也可以查看、修改和删除。
